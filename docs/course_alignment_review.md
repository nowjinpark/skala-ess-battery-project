## 예제 표현을 그대로 옮기지 않은 부분

1. **EOL 기준:** Scratch cell 20, 원본 JSON 930행은 `0.88 * nominal`을 기준선으로 사용한다. 정격 1.1Ah의 80%는 `1.1 * 0.8 = 0.88Ah`다. 현재 코드는 이 값을 사용한다. B1·B3의 근사 종료 라벨과 B2의 실제 교차 라벨을 구분하고 원본 타깃을 보존한다.
2. **그래프 색상 해석:** Scratch cell 20/21은 셀 ID 순서로 색을 부여한 뒤 장·단수명 색으로 해석한다. 현재 그림은 실제 수명 그룹이나 표시된 수명값을 기준으로 구분한다.
3. **상관과 인과:** Scratch cell 33, JSON 1279행의 “인과관계 확인”은 관측 상관만으로 확정할 수 없다. 현재 보고서는 배치·후속 충전 조건·소표본 등의 영향을 함께 설명한다. cell 26의 작은 Pearson r도 모든 비선형 관계의 부재를 증명하지 않는다.
4. **Pearson/Spearman 설명 수정:** 노트북 7절(0부터 센 markdown cell 18)을 “Pearson은 선형 관계, Spearman은 순위 기반 단조 관계를 요약한다”로 수정했다. 둘 다 인과나 최종 예측 성능을 확정하지 않는다. 계산식·코드 셀·실행 결과는 변경하지 않았다.
5. **가정의 범위:** 평균과 중앙값이 비슷하다는 사실만으로 데이터 편향이 없다고 확정하지 않고, 표준화가 임의의 분포를 정규분포로 만든다고 설명하지 않는다. 높은 쌍별 상관은 중복 정보 점검의 근거이며 모든 다중공선성 문제를 완전히 진단했다는 뜻은 아니다.

## 보고서 보완에 적용하는 해석 원칙

- 수명 분포에 실제 평균·표준편차·장단수명 비율을 제시하고, 충전 프로토콜 평균은 각 배치의 표본 수와 함께 비교한다. 평균 차이를 인과 효과로 표현하지 않는다.
- 모든 배치의 설명용 상관·분포 비교는 과제의 기술적 EDA로 표시한다. 모델 선택·데이터 기반 특성 조정은 B1 개발 구간에서 수행하며 B2·B3의 정답이나 점수로 튜닝하지 않는다. 이미 분포를 관찰한 B2를 완전히 미관찰한 테스트라고 부르지 않는다.
- ΔQ 평균·분산·최솟값은 서로 다른 곡선 요약이다. 세 통계를 비교하는 것은 특성 설계 근거를 넓히는 EDA이며, 어느 요약이 예측에 더 좋은지는 DAY 2의 동일 분할 비교로 확인한다.
- **대표 셀 3개의 두 직선 knee 근사는 분석자가 추가한 보조 탐색이다.** 수업에서 다룬 선형 기울기 개념을 활용하지만 수업의 필수 방법이나 공인된 knee 검출기로 제시하지 않는다. 대표 예시의 분할점은 평활화·구간 선택에 영향을 받을 수 있으며 전체 배터리의 정확한 knee를 검증한 결과가 아니다.
- 전체 수명의 두 직선 적합은 기술적 곡선 요약이다. 초기 100사이클 수명 예측 모델의 학습·검증과 구별하며, 그 과정에서 얻은 후반 기울기·분할점·knee 시점은 예측 입력에 넣지 않는다.
