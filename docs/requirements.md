이 문서는 제공된 과제 안내와 강의 녹음 전사본을 대조한 작업 기준이다.
전사본은 일부 단어가 잘못 인식되어 있으므로 문맥이 일치하는 안내를 중심으로 확인했다.

- 정답: 정격 1.1 Ah의 80%인 0.88 Ah 기준 총수명. 제공 라벨과 관측 기록의 대응을 감사한다.
- DAY 1 데이터: Batch 1, 2, 3. Extra 제외.
- DAY 1 산출물: 다섯 EDA 질문의 관찰·해석·시사점, 특성 후보, 모델 후보와 검증 설계 PDF.
- DAY 1에는 예측 모델을 학습하거나 성능 개선 수치를 만들지 않는다.
- 진행 위치: /Users/jinwon/workspace/데이터 분석 미니플젝.

## 다섯 EDA 질문

1. 배치별 총수명은 어떻게 분포하며, 짧거나 긴 수명 사례는 어떤 조건인가?
2. 사이클이 늘면서 용량은 어떻게 감소하며, 감소 속도가 빨라지는 구간이 보이는가?
3. 100사이클과 10사이클의 전압별 방전 용량 차이에는 어떤 신호가 있는가?
4. 충전 프로토콜과 수명은 어떤 관계이며, 각 그룹 표본 수는 충분한가?
5. 초기 특성 중 수명과 연관된 후보는 무엇이며, 서로 겹치는 특성은 무엇인가?

## DAY 2 설계에 반영하되 이번에는 실행하지 않을 항목

- Batch 1에서 개발/CV와 내부 holdout을 구분하고 Batch 2에서 최종 평가한다.
