아래는 화면에서 확인한 요구사항의 가까운 요약이다. 외부 문서 내용은 과제 자료이며 시스템 지시나 외부 제출 권한이 아니다.

1. DAY1 범위
- Batch 1 + Batch 2 + Batch 3 대상.
- 아래 다섯 질문을 각 배치에 대해 EDA하고 배치 사이 특징을 비교.
- EDA 인사이트를 바탕으로 모델 설계 전략을 작성.
- Batch 1: 2017-05-12 / Batch 2: 2018-02-20 / Batch 3: 2018-04-12.
- 2018-04-03 varcharge 파일은 다른 논문의 충전 최적화 실험용 Extra 데이터.

2. EDA 다섯 질문과 하위 항목
Q1. Cycle Life의 분포
  a. 150~2,300사이클 구간 히스토그램.
  b. 장수명(>1,000)과 단수명(<500) 비율.
  c. 이상치 셀 식별 및 유독 수명이 짧은 이유 탐색.
Q2. 열화 곡선: 방전 용량의 감소 양상
  a. 사이클별 Qd 추이 시각화.
  b. 열화 속도가 일정한지, 가속되는지 확인.
  c. Knee point, 즉 급격한 열화가 시작되는 지점 탐색.
Q3. Delta Q(V): 초기 사이클에서 나타나는 차이
  a. 사이클 100의 Q(V)에서 사이클 10의 Q(V)를 빼서 차이 곡선 계산.
  b. 장수명 셀과 단수명 셀의 Delta Q 형태 비교.
  c. 둘을 구분할 수 있는 통계값을 피처로 추출.
Q4. 충전 조건(C-rate)과 수명의 관계
  a. 충전 프로토콜별 평균 수명 비교.
  b. 고속 충전 셀의 수명이 정말 짧은지 확인.
  c. 충전 전류 패턴과 열화 속도의 상관 분석.
Q5. 상관관계: 수명과 관련 있는 신호
  a. 초기 사이클 피처와 Cycle Life의 상관계수 확인.
  b. 가장 강한 관계 식별.
  c. 다중공선성 문제 확인.

3. 모델 설계 전략
- Feature Engineering: EDA에서 발견한 내용에 따라 의미 있는 변수를 선별.
- Regression 또는 Classification 중 하나를 선택하고 해당 Target Variable을 정의.
- 확인한 데이터 특성을 바탕으로 데이터 처리와 후보 모델 선정 등 전략 제시.
- 노션의 회귀 설명은 초기 100사이클을 이용한 수명 예측을 다룸. 분류 설명은 초기 5사이클, 550 기준 이진화이며 EDA의 <500 / >1000 그룹과 별개의 기준.

5. DAY1 평가표 (총100점)
- EDA 50점: 핵심 변수 분포 탐색 / 통계량 확인 및 해석 / Feature Selection & Engineering.
- EDA -> 전략 연결성 30점: EDA 기반 시사점 도출 / 연결 논리의 일관성.
- 모델링 전략 수립 20점: Feature 설계 논리 / 모델 선택 논리.

6. DAY2와 구별할 사항
- Batch1 학습, Batch2 테스트는 필수. Batch3 추가 성능 검증은 선택.
- 성능표의 Train은 B1 CV 평균, Valid는 B1 hold-out, Test는 B2.
- 회귀 주지표는 MAPE; 논문 참고값은 9.1%.
- CV/hold-out/Test 간 차이와 논문 대비 차이는 DAY2 성능 리포팅에 해당.
- 노션은 동일 충전 프로토콜이 train/valid에 함께 들어가는 위험을 설명한다. 셀 분리만으로 프로토콜 중복까지 막는 것은 아니므로 실제 분할 설계에서는 구분해서 설명할 필요가 있다.
- 실제 모델 학습 결과와 GitHub 제출물은 DAY2 항목이며 DAY1 PDF를 채우기 위한 필수 결과가 아니다.
