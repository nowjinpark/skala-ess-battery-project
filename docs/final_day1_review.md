## 계산·표현·레이아웃 확인

변화량-기울기의 r은 B1/B2/B3=0.986/0.889/0.993, B2 충전 시간-로그 분산은0.957입니다. B1의 첫8C·후속3.6C가 같은 세 정책은 전환 SOC15/25/35%에서 평균수명1008.5/676.5/607.5사이클이며 각 n=2입니다. PDF와 저장 자료의 값이 일치합니다.

6쪽 모두 표·축·범례·본문의 잘림과 겹침을 발견하지 않았습니다. PDF 추출 텍스트의 NUL은0개이고 설명은 존댓말로 정리되어 있습니다. 색상 외에도 모양·선·숫자로 구분합니다.

## 해석의 한계

- 첫·후속 전류와 전환 SOC의 개별 상관·정책 그룹 비교는 독립적인 인과 효과를 분리한 분석이 아닙니다. 전체40그룹 중4그룹은 n=1입니다.
- 쌍별 높은 상관은 중복 정보 점검이며 모든 형태의 다중공선성을 완전히 진단한 것은 아닙니다. |r|≥0.85는 설명용 선별 기준이며 유의성 검정이나 자동 삭제 기준이 아닙니다.
- 대표3셀의 knee 근사는 탐색 결과입니다. 평활화·선택 구간에 영향을 받으며 전체 셀의 정확한 knee를 검증하지 않습니다.
- B1·B3의 제공 근사 수명과 B2의 관측 교차 수명, 원논문과 다른 배치 버전을 구분합니다. B3 곡선 비교는 사이클·전압 격자를 확인했어도 측정 조건의 동일성을 보장하지 않습니다.
- 후기 기울기·knee와 B2·B3 전체 상관은 설명용입니다. 초기 예측 입력에 미래 정보를 넣거나 기존 모델 선택을 바꾸는 근거로 쓰지 않습니다.
