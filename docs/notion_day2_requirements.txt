2. DAY2 필수/선택 범위
- 목표: 모델 설계 전략을 기반으로 최적 모델을 개발하고 논문 성능과 비교.
- 필수 Modeling: Batch1을 학습 데이터셋, Batch2를 테스트 데이터셋으로 사용.
- 선택 Additional: 개발한 최적 모델로 Batch3에서 추가 성능 검증.
- Batch3 성능은 배치 차이 때문에 저하될 수 있다는 안내가 있다.
- Batch3 참고 토글: 배치별 수명 분포 차이, 충전 커브 시작 시점 차이로 Qdlin 단순 비교가 왜곡될 가능성, 수집 시기 차이와 일부 셀 품질 문제/원논문 제외 사례를 언급한다.
- 이 페이지는 특정 모델 종류, 딥러닝, 후보 모델 개수, GridSearch/RandomizedSearch 등의 튜닝 알고리즘, 검색 범위, CV fold 수, hold-out 비율, seed를 고정하지 않는다. 이 값들은 DAY1 설계와 데이터 조건에 따라 정하고 실제 실행을 기록해야 한다.
- '최적 모델'은 탐색한 후보와 검증 조건 안에서 선택된 모델로 표현한다. 전역 최적성을 증명하라는 요구로 해석하지 않는다.

3. 분할과 성능표에서의 의미
- Train (Batch1 CV): Batch1 내부 교차검증의 평균 성능.
- Valid (Batch1 Hold-out): Batch1 내부 별도 hold-out 검증 성능.
- Test (Batch2): Batch2의 최종 평가 성능.
- 원문은 셀별 충전 프로토콜 차이와 동일 프로토콜 셀이 train/valid에 섞이는 위험을 들어 hold-out을 별도로 두는 이유를 설명한다.
- 검토자 구분: 셀 단위 분리는 같은 셀의 cycle 행이 분할 사이에 섞이는 것을 막지만, 같은 충전 프로토콜의 서로 다른 셀까지 분리한다는 보장은 아니다. 일반 CV 자체가 언제나 누수이거나 hold-out 자체가 프로토콜 중복을 없애는 것으로 설명하지 않는다.
- 원문에는 전처리/특성 선택/튜닝의 세부 구현법이 나열돼 있지 않다. 기존 수업의 훈련 fold 내부 fit, 미래 정보 제외, 테스트 점수로 튜닝하지 않는 원칙과 DAY1 설계를 구현한다.

4. 회귀 필수 성능 보고 형식
열: 구분 / MAPE(%) / 비고.
행:
  1) Train (Batch1 CV)
  2) Valid (Batch1 Hold-out)
  3) Test (Batch2)
  4) Gap (Train-Valid): 과적합 확인. 원문 비고는 (+)이면 과적합 의심.
  5) Gap (Valid-Test): 배치 간 일반화 차이 확인. 원문 비고는 (+)이면 일반화 저하 의심.
  6) Gap (Target-Test): 논문 참고값과의 차이. Target=MAPE9.1%.
- DAY2 Deliverables에서도 Batch2에 대한 논문 대비 Gap 반영을 별도로 명시한다.
- 회귀 주지표는 MAPE이며, 9.1%보다 낮아야 합격 또는 만점이라는 성능 문턱/배점 공식은 확인되지 않는다.
- MAE, RMSE, R²는 보조 설명으로 사용할 수 있으나 이 페이지의 필수 성능표 열은 MAPE이다.

5. Gap 방향의 명시가 필요한 이유
[원문과 검토자 권고를 구별]
- 원문의 행명은 Train-Valid, Valid-Test, Target-Test이며 산술식을 별도로 쓰지 않는다.
- 회귀에서는 MAPE가 작을수록 좋으므로 행명을 그대로 앞-뒤로 계산하면 원문의 '(+)이면 악화' 설명과 반대가 된다.
- 이번 회귀 결과에는 식을 명시해 모호함을 해소한다: Valid MAPE - CV MAPE / Batch2 MAPE - Valid MAPE / Batch2 MAPE - 9.1%.
- MAPE 자체는 %, MAPE 사이의 차이는 퍼센트포인트(%p)로 표시한다.
- 9.1% 비교는 과제의 참고 목표 대비 차이이며, 다른 배치 버전·정제·라벨·분할 조건까지 동일하다는 주장은 별도 근거가 필요하다.

6. Batch3까지 수행할 때의 추가 보고
- Batch2 결과와 나란히 두고 배치 간 일반화 수준을 해석.
- 기본 성능표에 Test (Batch3), Gap (Batch2-Batch3), Batch3의 Gap (Target-Test)를 추가.
- B2/B3 차이가 크면 특정 배치에 피처가 맞춰졌을 가능성과 다른 가능한 원인을 분석.
- 회귀의 추가 Gap도 사용한 계산 방향을 직접 적는다. 예: MAPE_B3 - MAPE_B2, MAPE_B3 - 9.1%.
- B3는 새 모델을 골라 최적화하는 데이터가 아니라 이미 선택한 모델을 추가 검증하는 데이터라는 문맥이다.

7. 분류 참고 형식 (현재 회귀 선택 시 별도 수행 불필요)
- 열: 구분 / F1-Score / Accuracy / 비고.
- 행: B1 CV, B1 hold-out, B2, 세 Gap.
- 논문 참고: 테스트오차4.9%(1-Accuracy), 즉 Accuracy95.1%.
- Batch3 추가 표도 같은 지표로 Test(Batch3), B2-B3 차이, 논문 비교를 추가.
- 원문 Performance Metric 목록에서 F1-Score/Accuracy 앞에도 Regression이라고 표기돼 있으나, 별도 분류 표와 문맥상 Classification을 뜻하는 오기로 판단한다. 회귀에 F1/Accuracy를 적용하지 않는다.

10. 원문 설명과 실제 데이터 사이의 구별
- Batch3 참고 토글에는 'Batch1/2는 유사하지만 Batch3는 분포 차이'라는 설명이 있다. 현재 확보한 과제 Batch2(2018-02-20)의 EDA에서는 Batch1보다 단수명 비중이 높았다. 원문의 일반 설명을 관측 결과 대신 복사하지 않는다.
- 원문은 과제 Batch2를 원논문의1차 테스트셋이라고 명명하지만, 현재 프로젝트의 원본·저자 코드 감사에서는 원저자 코드의 Batch2 날짜2017-06-30과 다름을 확인했다. 최종 보고서는 이 실제 사용 조건을 보존한다.
- B1/B3 제공 근사 종료 라벨과 B2 실제80% 교차 라벨의 차이는 프로젝트 데이터 감사 결과이며, 원문 일반 target 설명만으로 그 차이가 사라지지 않는다.
- Batch3 Qdlin 비교에 대한 경고는 해당 변수의 실제 전압 격자·cycle 참조를 확인해야 한다는 검토 사항이지, 임의 시간 정렬·라벨 변경·타 배치 연결을 허용하는 지시는 아니다.
