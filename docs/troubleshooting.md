# DAY 1 분석 기록: 확인한 문제와 판단 근거

이 기록은 실제 데이터와 실행 결과에 근거한다. 아직 예측 모델을 학습하지 않았으며 성능 개선 수치는 없다.

## 1. 같은 'Batch 2' 이름이 다른 실험 파일을 가리켰다

- 처음 가설: 원저자의 Batch 1→Batch 2 연결 코드를 재사용할 수 있을 것이다.
- 확인: 원저자 `BuildPkl_Batch2.ipynb`는 2017-06-30(48셀)을 읽는다. 과제 파일 내부 `batch_date`는 2018-02-20이고 셀은 47개다.
- 문제: 원저자 b2c7/8/9/15/16의 고정 인덱스를 그대로 사용하면 이번 자료의 다른 배터리를 연결하거나 삭제하게 된다.
- 결정: 현재 Batch 2에는 그 연결·삭제·수명 가산 규칙을 적용하지 않았다. 입력 파일명·내부 날짜·배터리 수를 함께 확인했다.
- 남은 한계: barcode/channel은 MATLAB 객체 문자열(MCOS)이라 이 로더에서는 해독하지 못했다. 파일 내부 ID의 비중복이 물리적 배터리의 비중복을 증명하는 것은 아니다.

## 2. '관측 길이보다 큰 라벨은 모두 제외' 규칙이 Batch 1 전체를 제외했다

- 실행 결과: 첫 검증 기준에서 Batch 1 분석 대상이 0개가 되어 내부 분할 단계가 실패했다.
- 재확인: 46개 모두 `cycle_life_raw = n_summary + 1`이었다. 기록 안에서 엄격한 `QD < 0.88 Ah` 교차는 없었다.
- 원저자 근거: B1 c8/10/12/13/22는 비완주로 제외했다. c0~4는 다른 2017-06-30 기록과 연결했는데 이 실습 입력에는 해당 파일이 없다.
- 결정: 위 10개를 분리하고 나머지 36개는 **제공된 근사 종료 라벨**로 유지했다. 타깃 값 자체는 변경하지 않았다.
- 실물 확인: 유지 36개의 마지막 QD는 0.8800565~0.8833632 Ah, 제외 10개는 0.913119~1.043279 Ah다. 0.885 Ah는 이 차이를 확인하는 보조 점검값이며 새 EOL 정의가 아니다.
- 남은 한계: 이 36개도 실제 다음 사이클에 반드시 EOL에 도달했다고 확인된 것은 아니다. B2의 직접 관측 라벨과 확실성이 다르다. 이를 해결 완료 또는 완전히 검증된 실제 수명이라고 표현하지 않는다.

## 3. Batch 2에는 수명 라벨이 없는 다른 충전 실험 기록이 함께 있다

- 확인: b2c22/23/35/36/37/38/39/40의 `cycle_life_raw`가 결측이다. VarCharge 또는 SLOWCYCLE 정책이 포함된다.
- 결정: 원본 47개는 보존하고 이 8개는 수명 타깃 분석에서 제외했다. 남은 39개는 제공 라벨과 실제 QD<0.88 최초 사이클이 모두 일치했다.
- 남은 한계: 라벨이 있는 표본만 남기면 분석 대상 집단이 달라진다. 원본·분석 대상 분포와 제외 사유를 같이 제시한다.

## 4. 초기 내부저항이 0으로 기록된 셀의 평균을 어떻게 계산할 것인가

- 확인: Batch 2 분석 대상 중 6개는 초기 2~100사이클에서 양의 내부저항이 없다.
- 결정: 0을 정상 저항값으로 평균내지 않고 결측으로 보존했다. 100사이클 이후 측정값으로 채우지 않았다.
- DAY 2 계획: 각 학습 fold에서 산출한 중앙값으로 대체하고, 내부저항 특성을 제외한 모델과 비교한다. 아직 성능 차이는 확인 전이다.

## 5. 용량 변화량과 기울기는 거의 같은 정보를 담고 있다

- 확인: Batch 1 개발 표본 28개에서 10→100사이클 용량 변화량과 선형 기울기의 상관은 약 0.98이다.
- 결정: 후보를 모두 무조건 넣기보다 한쪽을 선택한 집합과 Ridge를 비교하도록 설계했다.
- DAY 2 계획: 기본 집합과 Delta Q 분산 추가 집합을 같은 CV 분할에서 비교한다. Delta Q와 수명의 상관 -0.782가 예측 성능 개선을 보장하는 것은 아니다.

## 6. Batch 3도 직접 EOL이 관측된 라벨이 아니었다

- 확인: 이번 파일은 원저자 Batch 3와 동일한 2018-04-12, 원본 46개다. 유한 수명 라벨 44개 모두 `n_summary+1`이며 46개 전부에서 `QD<0.88 Ah` 교차가 관측되지 않았다.
- 원저자 제외 근거: b3c37은 수집 문제, b3c23/32는 미완료·수명 결측, b3c2/42/43은 잡음이다. MATLAB의 순차 삭제 인덱스를 원본 ID로 환산해 Python 제외 목록과 대조했다.
- 결정: 원저자 제외 6개를 분리하고 나머지 40개는 제공 근사 종료 라벨로 유지했다. 마지막 QD는 0.88000458~0.88167018 Ah다. 임의로 수명을 연장하거나 임계값 교차를 추정하지 않았다.
- 의미: B1·B3의 제공 근사 라벨과 B2의 직접 관측 라벨은 확실성이 다르다. 배치 간 분포 차이를 충전 조건이나 모델 성능 문제만으로 설명하지 않는다.

## 7. 강의의 'Batch 3 선택'은 DAY 2 추가 평가를 뜻했다

- 확인: 새 녹음본 315~318행은 DAY 1에서 Extra를 제외한 세 배치를 활용하라고 안내한다. 348~376행의 Batch 3 선택 사항은 DAY 2 추가 모델 평가다.
- 결정: DAY 1은 B1·B2·B3 EDA로 수정하고, B3는 `Batch3_EDA_only`로 기록했다. 모델용 피처 판단은 B1 개발 28개로 유지했다.
- 결과: B3 추가 전후 B1·B2의 분석 대상·셀 ID별 분할 역할과 특성 상관 결과가 같다. 잘못 이해했던 범위를 녹음 근거로 수정했으며 이를 모델 개선 성과로 표현하지 않는다.

## 사전 검증한 사항

- 실제 summary.cycle에서 10과 100을 찾아 HDF5 곡선 슬롯에 대응했다. 이번 세 파일에서는 각각 zero-based 9와 99였다.
- 115개 분석 대상 전부에서 저장된 Delta Q가 Q100-Q10인지, 로그 분산이 재계산값과 맞는지 확인했다.
- 배터리 ID는 Batch1 개발 28개 / holdout 8개 / Batch2 평가 39개 / Batch3 EDA 전용 40개로 분리했고 겹치지 않는다. B1·B2의 이전 분할과 셀 ID별 역할이 정확히 같다는 것도 확인했다.
- 모델 입력 후보의 관측 범위는 100사이클 이내다. 열화 후반·EOL 판정 정보는 입력 후보에 포함하지 않았다.
- 전체 행 116,722개는 배터리 139개의 반복 측정 기록이다. 독립 배터리 116,722개로 해석하지 않는다.

## 재사용한 수업 개념

- 기술통계: 원본/분석 대상의 수명 분포, 중앙값, 장·단수명 비율.
- 상관분석: Pearson/Spearman, 배치별 관계 차이, 인과관계와의 구분.
- Feature Engineering: 용량 수준·변화량·기울기, 곡선 차이의 분산과 로그.
- 다중공선성: 변화량과 기울기의 높은 중복, 규제와 특성 집합 비교 계획.
- 검증: 배터리 단위 분할, 학습 fold 내부 전처리, Batch 2 EDA 관찰 범위 공개.
- 도메인 해석: 수명 과대예측과 과소예측의 운영상 의미. 실제 비용 절감이나 운영 안전성 향상을 실증한 프로젝트는 아니다.
