# 데이터 출처와 포함 범위

- 출처: [MIT-Stanford Dataset / itshpark](https://www.kaggle.com/datasets/itshpark/data-driven-prediction-of-battery-cycle)
- 원 연구: Severson et al. (2019), DOI: 10.1038/s41560-019-0356-8.
- Kaggle 상세 메타데이터의 라이선스 표기: `Other (specified in description)` (2026-10-01 확인). 이 저장소는 원본 데이터에 별도의 라이선스를 부여하지 않는다.
- `processed/`는 과제에서 내려받은 세 MAT 파일을 코드로 추출·정리한 수치 자료다. 재현 가능한 분석을 위해 특성·요약·선택한 초기 곡선을 포함한다.
- 수 GB의 원본 MAT, 내려받은 압축파일, 수업 녹음·강의 원문은 포함하지 않는다. 원본은 Kaggle에서 직접 내려받아 `raw/`에 둔다.
- 세 파일 이름, 사용 배치, 정제·타깃 정의 및 분석 한계는 최상위 README를 참고한다.
